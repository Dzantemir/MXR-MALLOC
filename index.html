MxR-malloc — simulator v3 · audit sync

ESP8266 RTOS SDK · behavioral model aligned with the 2026-09-29 audit fixes (not a CPU or concurrency emulator) · DRAM + IRAM · EXEC hard-bound to reserve zone · cross-region with independent DRAM/IRAM guards

Settings (Kconfig.projbuild)

All options apply instantly. Structural changes (arena sizes, region layout, IRAM toggle) re-initialize the heap automatically. Sub-options collapse when their parent is disabled.

Arenas

Off: ordinary malloc uses SDK-compatible 32BIT. On: ordinary malloc uses 8BIT|32BIT (DRAM only). Explicit heap_caps operations and heap queries keep their requested capabilities.

The fallback limit applies to the final descriptor size, including alignment, canaries and anti-sliver expansion.
EXEC zone = [0, reserve). EXEC blocks never leave it. reserve = 0 → EXEC allocations are rejected entirely.

Descriptor tables

Dynamic INIT and CHUNK are shared settings. Each arena clamps INIT to its own MAX_DESC. Growth requires a complete CHUNK and a free tail.

Placement — Descriptor table / Allocator state (Kconfig)

Mirrors Kconfig: Descriptor table placement (MXR_DESC_IN_IRAM_TEXT / _BSS) and Allocator state placement (MXR_STATE_IN_IRAM = variant B / MXR_STATE_IN_DRAM = variant A). The state placement selector is available only with IRAM descriptor placement; IRAM state requires that placement (otherwise the C header emits #error).
Static data outside the arenas: descriptor tables MXR_MAX_DESC×8 (+ MXR_IRAM_MAX_DESC×8), excluding dynamic tables. Modeled state size depends on field widths, hint/bin settings, and the number of regions (DRAM + fallback). IRAM data must use aligned 32-bit accesses. Supported byte/halfword accesses enter LoadStoreErrorHandler for emulation; variant B widens fields to 32 bits and COMPACT_TYPES no longer applies to mxr_status_t/mxr_region_t. CMake maps .bss.mxriram through ld/mxr_sections.lf into SDK .iram0.bss; no SDK script patch is needed.
Static subtraction is off by default. The model excludes other globals, code, linker padding and SDK overhead; use the ELF map for the real budget.

Operations

Trace messages explain simulated events, not firmware logging. C canary/DFD errors only update counters inside the allocator; mxr_dump reports them later with cache enabled. Realloc copies live payloads outside its lock and re-finds the old descriptor on release. This single-threaded model does not measure interrupt latency, prove cache-off safety, or emulate task interleavings. Status is detailed; firmware MINIMAL dump skips region snapshots.
